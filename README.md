# ColabVerse 🚀

**Connect. Learn. Collaborate.**

ColabVerse is a developer collaboration platform where programmers can connect, share knowledge, manage development groups, and work on projects together.

## ✨ Features

- **Developer Communities** — Create and join communities to connect with other developers.
- **Private Development Groups** — Build teams, invite members, and manage group permissions.
- **GitHub Integration** — Connect repositories and collaborate using GitHub.
- **Live Meetings** — Communicate through real-time voice and video meetings powered by LiveKit.
- **Developer Q&A** — Ask programming questions, share solutions, and help other developers.
- **Developer Profiles** — Showcase skills and connect with other programmers.
- **Google Authentication** — Register and sign in securely using Google.
- **Admin Moderation** — Manage reports and moderate community content.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python & Django | Backend development |

## ⚙️ Local Setup

**1. Clone the repository**

```bash
git clone https://github.com/danielakpa/code-view.git
cd code-view
```

**2. Create and activate a virtual environment**

```bash
python3 -m venv venv
source venv/bin/activate
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Configure environment variables**

Create a `.env` file and configure your Django, PostgreSQL, Google OAuth, GitHub, and LiveKit credentials.

**5. Run database migrations**

```bash
python3 manage.py migrate
```

**6. Start the development server**

```bash
python3 manage.py runserver
```
